How to read this

  • Direct costs: expenses recorded for the activity (or the part of a split expense).
  • Common costs: expenses for activities set as “shared” (General, Cleaning, Technical…), spread over the activities that earn revenue. Utility bills follow the percentages set in Activity settings. Other common costs follow the percentages set in Activity settings. Without a key — the same amount each. here shown on their own line instead. in proportion to their revenue, so busier activities carry more.
  • Pending expenses count until an admin rejects them. Rows always add up to the center's profit.
  • Change which activities are shared, on their own line, or part of another in Activity settings.
